# Data Visualization Associate Internship at Excelerate

## Overview

As a **Data Visualization Associate Intern** at Excelerate, I had the incredible opportunity to transform raw data into actionable insights through the creation of an interactive dashboard. This internship spanned **four weeks**, during which I honed my skills in data preprocessing, exploratory data analysis (EDA), and interactive dashboard design using **Google Data Studio**.

The internship's primary goal was to design a dashboard for Excelerate’s leadership team, enabling them to make informed decisions by visualizing trends, patterns, and outliers from the company's datasets. This journey involved close collaboration with a global team, analyzing data structures, and designing intuitive visualizations to highlight **key performance indicators (KPIs)**.

---

## Key Responsibilities

- **Data Preprocessing**: Preparing datasets for analysis and visualization.
- **Exploratory Data Analysis (EDA)**: Identifying patterns, trends, and outliers.
- **Wireframing Dashboards**: Designing layout and flow of the dashboard.
- **Dashboard Creation**: Developing and finalizing the dashboard in **Google Data Studio**.
- **Presentation**: Presenting the final dashboard to Excelerate’s directors.

---

## Internship Timeline

### **Week 1: Data Preprocessing and Exploratory Data Analysis (EDA)**

- Preprocessed two datasets:
  - **User Dataset**: Contained information about user interactions and behaviors.
  - **Opportunities Dataset**: Included details about business opportunities and metrics.
- Performed EDA to understand data distributions, correlations, and missing values.
- Used Python and libraries like **Pandas**, **NumPy**, and **Matplotlib** for analysis.

### **Week 2: Advanced Analysis and Dashboard Wireframing**

- Conducted deeper analysis on the datasets to extract actionable insights.
- Designed a wireframe for the dashboard:
  - Focused on KPI visualization.
  - Outlined sections for trends, patterns, and outliers.
  - Prioritized user-friendly navigation.

### **Week 3: Creating a Rough Dashboard**

- Built a sample dashboard in **Google Data Studio**:
  - Visualized key insights with charts, tables, and graphs.
  - Incorporated filters for dynamic data exploration.
  - Highlighted critical KPIs like revenue growth and user engagement metrics.

### **Week 4: Finalizing and Presenting the Dashboard**

- Refined the dashboard based on team feedback:
  - Improved design aesthetics and interactivity.
  - Enhanced clarity and storytelling through visual elements.
- Presented the finalized dashboard to the directors:
  - Explained insights derived from the data.
  - Demonstrated the dashboard’s usability and value for decision-making.
